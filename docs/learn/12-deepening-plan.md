## What the paid course covers (topic outline only)

Five lessons: introduction to HIPAA; using and disclosing PHI (with case studies and a "view answer" step); HIPAA Privacy
(including the business associate contract provisions as a checklist); HIPAA Security (the three safeguard families as a
diagram); and a closing lesson on breach and enforcement. Its depth comes from short, single-idea pages, a worked case after each
rule, and a checklist or diagram wherever there is a list.

## Target: HIPAA course v2 (Full track about 125 minutes, Essentials about 60)

Each module opens with "why this matters", teaches the rule, shows it on the job, works a case, and ends with a glossary and key
points. Each screen holds one idea. Blocks: the existing set plus **table, layers, timeline, glossary and worked case** (Batch 1).

## Batch 1: what was added

Five lesson blocks, all plain validated data (no HTML), in `apps/learn/src/content/schema.ts` and rendered by
`apps/learn/src/components/content-blocks.tsx`:

| Block | Use | Limits |
| --- | --- | --- |
| `table` | Checklists and comparisons (for example the agreement provisions) | 2-4 columns, 1-10 rows, every row as wide as the heading row |
| `layers` | Things that stack (the three safeguard families) | 2-6 items |
| `timeline` | A sequence in time (the days after a breach) | 2-8 items |
| `glossary` | Terms introduced in the module, reopenable | 2-10 terms |
| `case` | A worked case: read, think, then show the answer (not graded) | scenario and answer up to 900 characters |

The studio (add, edit, reorder, preview, diff) and the reviewer export handle all five; the same text checks apply (no markup,
no web addresses, no real-looking identifiers). A worked case counts as interactive in the "has something to do" check.
