# Background music for the recap videos

`zephiramusic-lofi-gaming-606302.mp3` is the background track mixed under the narration in every recap video (HIPAA, Cybersecurity and
Customer Service) at 0.12 volume. It is a free-licence Pixabay track ("Lofi Gaming" by Zephira Music, Pixabay id 606302), downloaded by the
owner on 2026-10-21; Pixabay's content licence allows use in videos without attribution. Kept here (committed) so the videos can be rebuilt on
any computer: the pipeline looks for `audio/cs/bgm.mp3` and `learn/narrate-learn.cjs` copies this file there when it is missing.
Do not delete it. If the licence terms are ever in doubt, check the Pixabay page for track 606302 before using it in anything new.
