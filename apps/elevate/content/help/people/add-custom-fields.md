A **custom field** is an extra detail HR wants on every profile, for example shirt size or preferred shift.

# Never use it for private IDs

Custom fields are never encrypted, so do not use them for government IDs, bank details or pay. Those have their own protected fields.

# Add a field

1. Click **People** in the left menu, then **Manage**, then **Custom fields**.
2. Fill in:
   - **Label**: what people read, such as "Shirt size".
   - **Key**: lowercase letters, numbers and underscores. It cannot be changed later.
   - **Type**: **text**, **number**, **date** or **select** (a list of choices).
   - **Who can see it**: **HR only** or **HR and the person**.
   - **Options (one per line)**, for a select field.
   - **Required**, if every profile must have it.
3. Click **Add field**. A message says **Field added.**

To retire a field, archive it. A box asks you to confirm. It disappears from profiles, and the saved values are kept.

If there are none yet, the page says **No custom fields yet.**

![Custom fields: label, key, type, who can see it.](help:add-custom-fields/01-fields.png)

# Where it shows

The field appears on people's profiles. HR fills it in, or the person does when they can see it.

# Good to know

- Keep the number small. Every extra field is one more thing to keep up to date.
- Choose **HR only** for anything people should not see about each other.

# Common mistakes

- **Putting a bank number or ID in a custom field.** Use the protected fields instead.
- **A key with capitals or spaces.** It must be lowercase with underscores.

# Try it yourself

- Open **Custom fields** and read the choices on the form.
