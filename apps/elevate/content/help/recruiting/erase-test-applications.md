While you practice, you may create test applications. This guide removes them completely. **It cannot be undone**, so use it for test data only.

# What it removes

The application, the applicant, their resume, notes, interviews, scorecards and queued emails. If it was the applicant's only application, the applicant is removed too.

# When it is refused

An applicant who has an offer, an onboarding case or a hire cannot be erased.

# Steps

1. Open the test application from its job pipeline.
2. Scroll to the erase section. It says it erases the application for good.
3. Type **DELETE** in the box **Type DELETE to confirm**.
4. Confirm. A message says **Application erased.**

The audit log keeps ids and counts, never the name.

# Common mistakes

- **Erasing a real applicant.** Close a real application instead, and let the retention rules remove it later.
- **Typing delete in small letters.** Type DELETE in capitals.

# Try it yourself

- Create a test application on a test job, then erase it.
