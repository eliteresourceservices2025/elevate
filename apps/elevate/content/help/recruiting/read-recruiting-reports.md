The **Recruiting reports** page shows counts only. It never shows names. Use it to see where your hiring slows down and which ads bring good applicants.

# Open it

1. Click **Recruiting** in the left menu.
2. Click **More**, then **Reports**.

# Choose what to look at

At the top, set **Applied from** and **Applied to** (it starts with the last 90 days), choose a **Job** or **All jobs**, and click **Show report**. The report counts the applications that came in between those dates.

![The reports page. Each box answers one question.](help:read-recruiting-reports/01-reports.png)

# The boxes

- **How far applications got.** How many applications reached each stage. Someone who moved past a stage counts at the earlier ones too, so the bars only go down.
- **Time in each stage.** The middle value of how long applications stayed in each stage. A short time is not always good, and a long time points to a stage where people wait.
- **Where applicants come from.** For each source: how many applied, how many reached an interview and how many were hired. See "Tag applicants and see where they come from".
- **How applications ended.** How many were **Rejected**, **Not qualified** or **Withdrew**.
- **Waiting longest.** Jobs with open applications that have not changed for 14 days or more. This one shows today's situation, whatever the dates above.

# Using the reports well

- Compare one job at a time. Different jobs move at different speeds.
- A small number of applications gives rough numbers. Do not draw big conclusions from a handful.
- There is no report on each recruiter on purpose. The reports are for the process, not to rank people.

# Common mistakes

- **Reading a source with only a few applicants as a trend.**
- **Forgetting that many people did not say where they heard.** They are counted under **Not said**.
- **Looking for names.** There are none here. Go to the **Applicants** page for people.

# Try it yourself

- Open the report for the last 90 days, then choose one job.
- Find the stage where applications wait the longest.
