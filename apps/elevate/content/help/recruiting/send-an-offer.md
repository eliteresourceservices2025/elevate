An offer is a letter the applicant signs online. They do not need an ELEVATE account. The letter says "independent contractor". Pay is written as a free-text note only. ELEVATE does not store or work out pay.

# Before you start

- The applicant must be at the **Offer** stage. If they are not, the offer panel says **Move the applicant to the Offer stage to make an offer.**
- You need an offer template. If there is none, the panel says so. HR creates one under **Offer templates** on the Recruiting page.

# Create or change an offer template

1. On **Recruiting**, open **Offer templates**.
2. Give the template a name and write the **Letter**. Use the **Merge fields you can use** list for details that fill in by themselves: the applicant's name, offer date, expiry date, role, start date, client and pay note.
3. Check the **Preview (with sample values)**.
4. Click **Save template**. A message says **Template saved.**

An unknown field name cannot be saved. Counsel should review the wording before real use.

# Make the offer

1. Open the applicant's page and find **Offer and hiring**.
2. Open **Make an offer**.
3. Choose the **Template**. Fill in:
   - **Legal first name** and **Legal last name**
   - **Work email (they sign in with it)**
   - **Role**, **Position (optional)**, **Team (optional)** and **Client (optional)**
   - **Start date**
   - **Pay note (free text, shown in the letter)**
   - **Days to accept**
   - **Countersigner (optional, signs after the applicant)**
4. Click **Preview the letter** to read it.
5. Either **Send offer**, or save it as a draft to send later. A message says **Saved as a draft.**

The applicant gets an email with a link. They ask for a 6-digit code sent to the same email address, then read and sign the letter.

# Track the status

The offer shows one of: **Draft**, **Sent**, **Signed**, **Declined**, **Expired** or **Withdrawn**. If you chose a countersigner, you also see whether it is countersigned.

# Resend or withdraw

- **Resend** sends a new link if they did not get it. The old link stops working.
- **Withdraw** cancels the offer. A box asks you to confirm. The applicant's link stops working.

Only one offer can be live at a time. Once you send it, editing the template never changes the letter already sent.

# Common mistakes

- **A work email with a typo.** The code goes to that address. Withdraw and send again.
- **Promising pay in the letter.** Keep the pay note to what was agreed in writing.

# Try it yourself

- Preview a letter for a test applicant at the Offer stage.
- Save it as a draft, then send it to a test address you own.
