ELEVATE asks everyone for a 6-digit code when they sign in. The code comes from an authenticator app on your phone. This protects your account and the information in it. You set it up once.

# Before you start

- Install an authenticator app on your phone. **Google Authenticator**, **Microsoft Authenticator** and **1Password** all work.
- Have your phone ready next to your computer.

# Step 1: Sign in

Type your email and password on the sign-in page and click **Sign in**. Or click **Continue with Google**.

# Step 2: Scan the code

The page **Set up two-step verification** shows a square picture (a QR code). Open your authenticator app, choose to add an account and scan the picture.

If you cannot scan it, type the long key shown under the picture into the app instead. It is next to the words **Cannot scan? Enter this key instead**.

# Step 3: Type the 6-digit code

Your app now shows a 6-digit number that changes every 30 seconds. Type it in the **6-digit code** box and click **Verify**.

# Next time you sign in

After your email and password, the page **Two-step verification** asks for the current 6-digit code from your app. Type it and click **Verify**.

# Common mistakes

- **The code is rejected.** It changes every 30 seconds. Wait for a new one and type it again. Also check that your phone's clock is on automatic time.
- **You got a new phone.** Ask a Super Admin to reset your authenticator. You will set it up again on the new phone.

# Try it yourself

- Find your authenticator app and look at the code it shows.
- Sign out, then sign in again with the code.
