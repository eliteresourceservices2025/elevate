When someone sends a request from **Contact support**, HR is notified in ELEVATE and by email. The email carries a count and a link only, never the text.

# Open the inbox

Click **Contact support** in the left menu. As HR you see two lists:

- **Your requests**, the ones you sent yourself.
- **Inbox**, with the number of open requests.

![The support inbox, with the open requests.](help:handle-support-requests/01-support-inbox.png)

# Read a request

Each request shows the topic (*Signing in or my account*, *The time clock or my hours*, *Jibble or screenshots*, *My information or a record is wrong*, or *Something else*), a short title, the details and the page the person was on.

# Solve it

Fix what you can, then reply to the person directly. Common fixes are in these guides:

- Sign-in or authenticator: "Set up two-step sign-in" and "Roles and what each can do".
- Clock or hours: "Approve a time correction".
- Jibble: "Check the Jibble link".
- A wrong record: "Add or edit a person".

# Mark it handled

Click **Mark as handled**. A message says **Marked as handled.** It moves to **Handled**. Use **Reopen** if you need it again. A message says **Reopened.**

# Never ask for secrets

Never ask a person to send a password, a code or a government ID in a request.

# Common mistakes

- **Closing without replying.** Tell the person what you did.
- **Asking for a screenshot with client information.** Ask them to hide it first.

# Try it yourself

- Send a test request as yourself, then mark it handled.
