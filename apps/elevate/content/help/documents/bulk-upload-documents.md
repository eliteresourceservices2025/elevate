If you have many files to add, bulk upload saves time. It works on one person's record, or for company documents.

# Where to find it

- For a person: open their profile, click the **Documents** tab and use **Upload many files**.
- For company documents: click **Documents** in the left menu, open **Company documents** and use **Upload many files**.

![Upload many files: drag them into the box, then click Upload files.](help:bulk-upload-documents/01-bulk-upload.png)

# Steps

1. Drag the files into the box. It says **Drag and drop files here, or** choose them with the button.
2. You can add up to **50 files** in one go. If you add more, a message says how many did not fit.
3. Each file must be 10 MB or less, and a PDF, JPG, PNG, WEBP, DOC or DOCX. A file that is too big is marked as failed with the reason.
4. Click **Upload files**.

# After the upload

All files are saved as **Unsorted**. Give each one its type from the list: use **Set type** on its row. You can also verify them and move them into folders.

If some files failed, the rest still upload. The message **The upload did not go through** shows for a file that failed. Try that one again.

# Never upload client or patient information

Even in bulk. Check the files before you drop them in.

# Common mistakes

- **Leaving files Unsorted.** They are hard to find and do not count toward required documents. Set their types.
- **Uploading a scan with a client name.** Do not.

# Try it yourself

- Drag three small test files into a test person's record.
- Set the type of each.
